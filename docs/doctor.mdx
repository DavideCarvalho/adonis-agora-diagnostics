---
title: Health check
description: node ace agora:doctor checks the diagnostics configuration (and every other installed Agora lib) for what breaks in production, from the terminal or in CI.
icon: Stethoscope
---

`node ace agora:doctor` checks every installed `@adonis-agora` lib; `node ace diagnostics:doctor` checks diagnostics only.

```bash
node ace agora:doctor                  # every lib
node ace diagnostics:doctor            # diagnostics only
node ace agora:doctor --json --strict  # in CI: one JSON object, fail on warnings too
node ace agora:doctor --no-boot        # the app does not boot: config checks without booting
```

| Flag | |
| --- | --- |
| `--lib=diagnostics,durable` | only these libs |
| `--only=diagnostics.transport` | one check |
| `--deep` | also checks that reach a database, Redis or the network |
| `--json` | one JSON object on stdout |
| `--strict` | warnings fail too |
| `--verbose` | show skipped checks |
| `--no-boot` | do not boot the app (for when booting is what fails); runs the checks that only read config |

Exit code: `0` no error, `1` at least one error (or a warning with `--strict`), `2` the doctor could not run.

Add it to CI after the build:

```yaml title=".github/workflows/ci.yml"
- run: NODE_ENV=production node ace agora:doctor --json --strict
```

`node ace configure @adonis-agora/diagnostics` registers the commands. In an app configured before
they existed, add them to `adonisrc.ts`:

```ts title="adonisrc.ts"
commands: [
  () => import('@adonisjs/core/commands'),
  () => import('@adonis-agora/diagnostics/commands'),
],
```

## Checks

| Id | What it checks | Status |
| --- | --- | --- |
| `diagnostics.peers` | `@adonisjs/core`, and the transport peers you installed, are in the supported range | error |
| `diagnostics.agora-siblings` | no 0.x and 1.x `@adonis-agora` libs mixed | warn |
| `diagnostics.registered` | every installed Agora lib with checks has its provider registered | warn |
| `diagnostics.transport` | `default` names a transport; `redis` has `@adonisjs/redis` and its connection; `queue` has `@adonisjs/queue` configured; `durable` has `@adonis-agora/durable` installed and configured | error |
| `diagnostics.role` | `role: 'api'`/`'worker'` has a `default` transport; `forward` is not set without one | error / warn |
| `diagnostics.recent-buffer` | `recent.size` is a positive integer; the [recent-events buffer](/docs/diagnostics/mcp-tools#recent-events) is not forced on in production | error / warn |
| `diagnostics.listeners` | a custom `listenersPath` exists | warn |
| `diagnostics.otel` | the OpenTelemetry SDK packages are on one major line (`@adonisjs/otel` 2 is SDK 3) and `@opentelemetry/api` is installed once; reported by telescope instead when it is installed | error / warn |
